# Project Notes

## Goal
Create a very simple web app for a wedding studio to store and view customer details.

## Hosting preference
- Must be hostable on GitHub with minimal or near-zero cost.
- Keep architecture simple and low-maintenance.

## Data storage preference
- Avoid full DB if possible.
- Prefer minimal file-based storage (JSON or CSV), whichever is best for reliability and ease.

## Core use case
Store and later view customer records, including:
- Customer names
- Event/wedding dates and related details
- Photographer team name
- Videographer team name
- Package details
- Advance amount
- Due amount

## Next step
Design the simplest secure architecture for:
1. Data entry form
2. Save data
3. View/search existing entries
4. Deploy with minimal cost

User will provide more detailed data fields later.
